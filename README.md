Deutsch Lesen — Read and Learn Languages

Deutsch Lesen is a lightweight web application for learning languages through reading. It allows users to read texts, translate unfamiliar words, and build their own vocabulary list while reading.

The idea is simple: read, click, understand, and remember.

Features

- Load text files: open TXT files directly in the application.
- Paste text: insert text from articles, books, or other sources.
- Interactive translation: click an unfamiliar word to see its translation.
- Language selection: choose German or English as the source language.
- Translation languages: choose Russian or Ukrainian as the target language.
- Personal vocabulary: add unfamiliar words to your own dictionary for later review.
- Word list management: view saved words and clear the vocabulary list when needed.
- Separable verb highlighting: identify German separable verbs using a heuristic approach.
- Reading comfort: adjust the font size and switch the display theme.

Try It Online

No installation is required. Deutsch Lesen runs directly in a web browser.

Live application: https://olekenglab.github.io/Text_lesen/

How to Use

1. Open the application in your browser.
2. Load a TXT file or paste text into the editor.
3. Select the source language and the translation language.
4. Read the text and click on an unfamiliar word to see its translation.
5. Add useful words to your personal vocabulary list.
6. Adjust the font size and display theme to suit your preferences.

Translation

The application includes a local dictionary for the language pair German → Russian.

For other supported language combinations, an online translation service is required. Translation availability therefore depends on the selected language pair and the availability of the online service.

Separable Verbs

German separable verbs can be difficult for language learners because their prefixes may appear separately from the main verb.

Deutsch Lesen provides heuristic highlighting to help identify these constructions while reading. This feature is intended as a learning aid; its results may be inaccurate in complex sentences or unusual grammatical constructions.

Intended Use

Deutsch Lesen is designed for independent language learning, vocabulary building, and reading practice.

Instead of interrupting reading to search for every unfamiliar word manually, users can access translations directly from the text and collect useful vocabulary in one place.

Limitations

- Translation of language pairs other than German → Russian requires an online service.
- Separable verb highlighting is heuristic and may not always identify grammatical structures correctly.
- Translation accuracy depends on the available dictionary or online translation service.
